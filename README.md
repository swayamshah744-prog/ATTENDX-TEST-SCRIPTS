# AttendX Test Scripts

This repository contains sample test scripts for the AttendX
student attendance application.

## Files

1. login_test.py
   - Tests login using sample valid credentials.

2. attendance_test.py
   - Checks whether valid attendance details can be marked.

## Technology
- Python
- Git
- GitHub

## Execution

Run the scripts using:

python login_test.py
python attendance_test.py
